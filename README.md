# Win11Optimal

---

## MPO
MPO / Multiplane Overlay is a Windows graphics feature that lets the GPU compose multiple visual layers directly, improving efficiency but sometimes causing flickering, black screens, or stuttering.

---

## Prefetcher
Windows Prefetcher is a Windows feature that stores startup and app-loading patterns to help programs and the system boot faster.

---

## SysMain
SysMain / Superfetch is a Windows service that preloads frequently used apps and data into RAM to make them open faster.
